== はじめに
OpenShift Virtualization により、仮想マシンを最新の Kubernetes ベースのインフラストラクチャ上に移行できます。新規アプリケーションの開発・提供に加え、既存アプリケーションのモダナイゼーションも可能であり、仮想マシン、コンテナ、サーバーレス関数から構成されるアプリケーションを Kubernetes ネイティブのツールとパラダイムで一体管理できます。

本ロードショーでは、Red Hat OpenShift Virtualization をハンズオンで体験していただきます。

本イベントでは、仮想化管理者が日々のワークフローでよく遭遇する一般的な管理作業の多くを体験します。

*※皆様向けの構成で、除外した内容(MTV等)があります。また、コンテンツは機械翻訳を使用しています。*

== ロードショーに最も参加をおすすめする方

*仮想マシン管理者* — OpenShift Virtualization 上の仮想ゲストの日々の管理を担当する方。仮想ゲストのプロビジョニング、ゲストおよびゲスト内で動作するアプリケーションの日常管理を担うことが多いユーザーです。

*仮想インフラストラクチャ管理者* — OpenShift Virtualization ソリューションをホストする物理インフラストラクチャを担当する方。物理ハードウェア、ストレージ、ネットワークの変更を管理し、実行中の仮想マシンの日常運用に影響を与えます。

== ロードショーで扱うコンテンツ

以下の *7* つの主要セクションを扱います。

* _仮想マシン管理_: 仮想マシンの作成やリソース割り当ての変更など、仮想マシン管理の基礎を確認します。

* _既存仮想マシンの移行_: Migration Toolkit for Virtualization（MTV）を使用し、既存の VMware vSphere 環境から OpenShift Virtualization へ仮想マシンを移行します。

* _ストレージ管理_: OpenShift Virtualization では、多くの管理者に馴染みのあるストレージのパラダイムが変わります。本セクションでは、仮想マシンのストレージ管理に関連する多くの操作を体験します。

* _仮想マシンのバックアップとリカバリ_: 外部サイトへの VM バックアップや、災害発生時の復元など、追加の概念を紹介・実演します。

* _テンプレートと InstanceType の管理_: 仮想マシンのデプロイを効率化するため、管理者はテンプレートの作成や InstanceType の定義を行うことがよくあります。本セクションではこれらのプロセスに焦点を当てます。

* _仮想マシンとアプリケーションの操作_: 本セクションでは、インポートした仮想マシンに対して Day-2 操作を行い、Service と Route を通じて VM 上のアプリケーションを公開します。

* _ネットワーク管理_: デフォルトでは VM は OpenShift 上の Pod ネットワークに接続されます。本セクションでは、新しい L2 ネットワークマッピングの作成や、直接ネットワーク接続のための User Defined Networks（UDN）の利用を体験します。

== OpenShift Virtualization とは

* 現在のすべてのサブスクライバーは、OpenShift サブスクリプションの一部として OpenShift Virtualization を利用できます。OpenShift 4.5 以降、一般提供（GA）されています。
* OpenShift Virtualization は、CNCF（Cloud Native Computing Foundation）の incubating プロジェクトである KubeVirt プロジェクトの下で上流開発されている「container-native virtualization」技術に基づいています。
* Red Hat Enterprise Linux KVM ハイパーバイザー（RHEL KVM）を活用します。RHEL KVM は 15 年以上にわたり開発されてきた、世界中の多くの組織やクラウドサービスプロバイダーが利用する成熟した高性能なオープンソースハイパーバイザーです。
* OpenShift Virtualization は RHEL KVM ハイパーバイザーを活用し、VM を Kubernetes と KubeVirt によって管理します。OpenShift Virtualization の VM は、Kubernetes のスケジューリング、ネットワーク、ストレージインフラストラクチャを利用します。

* OpenShift Virtualization は、Red Hat の他の KVM 仮想化製品と同様のルールに従い、Microsoft Windows ゲストサポートについて SVVP 認証を取得しています。
* OpenShift Virtualization は現在、ベアメタル物理サーバー上でのみサポートされています。通常はオンプレミス、またはサポート対象のクラウドプロバイダー経由です。OpenStack や vSphere など仮想化インフラ上にデプロイされた OpenShift など、他のトポロジーへのサポートは現時点では利用できません。
* OpenShift Virtualization により、OpenShift は OpenShift クラスタ内のリソースへ仮想マシンをデプロイ、管理、接続できます。Kubernetes ネイティブな方法で VM に接続・管理し、Pipelines、GitOps、Service Mesh など OpenShift の機能を活用することも可能です。

== 従来の VM プラットフォームから切り替える理由

**クラウドネイティブ開発および/またはクラウドネイティブ運用の採用:**
Red Hat OpenShift は、スピード、俊敏性、信頼性、選択の自由をもってアプリケーションを構築するチームを支援します。構築場所を選んで本番モードでコードを実行。本当に重要な仕事に集中できます。

**完全なアプリ開発スタック:**
Red Hat OpenShift Dev Spaces（旧 Red Hat CodeReady Workspaces）、Runtimes、Integration and Process Automation、Serverless、Pipelines など、セキュリティを全体に組み込んだスタック。

**インフラストラクチャ支出をイノベーションへ:**
OpenShift ネイティブアーキテクチャにより、SDDC レガシーから軽量なコンテナネイティブフレームワークへ、重いコスト構造を変革します。

**リスク軽減:**
オンプレミスとパブリッククラウドの両方をサポートする OpenShift により、パブリッククラウドへのロックインに対する保険となります。

**インフラストラクチャからの独立性:**
Red Hat OpenShift は、ベアメタル、オンプレミス仮想化、パブリッククラウド上で一貫して動作し、デプロイと更新の究極の選択肢と柔軟性を提供します。

**純粋なオープンソースイノベーション:**
Kubernetes、serverless、service mesh、Kubernetes Operators などのイノベーションは、Red Hat がリードするオープンソースの速度によって支えられています。

== どの OpenShift サブスクリプションが適しているか

OpenShift は包括的なプラットフォームであり、すべての機能はエンドユーザーがいつでも利用できますが、その使用は購入したサブスクリプションによって管理されます。

OpenShift のサブスクリプションは次の 4 カテゴリのいずれかに分類され、いずれも OpenShift Virtualization へのアクセスを提供します。

**Red Hat OpenShift Platform Plus**
は、大規模なアプリケーションを構築、モダナイズ、デプロイするための統合プラットフォームです。マルチクラスタのセキュリティ、コンプライアンス、アプリケーションおよびデータ管理がインフラストラクチャ全体で機能し、ソフトウェアサプライチェーン全体で一貫性を提供します。Red Hat OpenShift Platform Plus は、ハイブリッドクラウド上でアプリを市場投入するための完全なサービスセットで、よりスマートかつ迅速に作業できます。

**Red Hat OpenShift Container Platform**
は、今日の AI 対応アプリを含む、大規模なアプリケーションの開発、モダナイズ、デプロイのための信頼性の高い包括的で一貫したプラットフォームです。選択したインフラストラクチャ上でアプリを市場投入するための完全なサービスセットで、より迅速にイノベーションを実現できます。

**Red Hat OpenShift Kubernetes Engine**
は、Red Hat OpenShift の基本機能を提供します。エンタープライズ対応の Kubernetes 環境へのフルアクセスや、データセンターで使用する可能性のある多くのソフトウェア要素との広範な互換性テストマトリクスなど、Red Hat OpenShift Container Platform が提供する機能のサブセットを提供します。

**Red Hat OpenShift Virtualization Engine**
は、Red Hat OpenShift の実績ある仮想化機能を提供し、仮想マシン（VM）のデプロイ、管理、スケーリングを可能にします。VM ワークロードに特化した合理化されたソリューションで、必要な分だけお支払いいただけます。
