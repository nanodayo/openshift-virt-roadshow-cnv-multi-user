== 重要なポイント

* OpenShift Virtualization はソリューション指向であり、成熟した安定したスケーラブルなソリューションを提供し、簡単に始められます。

* OpenShift Virtualization は、完全なハイブリッドクラウドアプリケーション開発プラットフォームを提供する OpenShift Platform Plus から、仮想化ワークロードのサポートに特化した OpenShift Virtualization Engine まで、Red Hat OpenShift のすべてのサブスクリプションレベルで利用できます。

* OpenShift Virtualization は、幅広いパートナープロダクトのエコシステムと完全に統合されており、日々新しい製品が追加されています。OpenShift Virtualization をサポートしているか、ご希望のハードウェアおよびソフトウェアベンダーにご確認ください。

* OpenShift Virtualization は、従来のワークロードの強固な基盤を築きながら、モダンなアプリケーションプラットフォームで将来に向けたスキルを構築するのに役立ちます。

=== Red Hat Learning Services: DO317 Managing Virtual Machines with Red Hat OpenShift Virtualization

* OpenShift クラスター上で VM を作成、アクセス、管理するために必要なスキル。
* コンテナと同様に Kubernetes 機能で CPU、メモリ、ストレージ、ネットワークリソースの VM からの使用とアクセスを制御するために必要なスキル。
* OpenShift Virtualization の拡張と標準 Kubernetes 機能を使用して VM の高可用性（HA）を管理するサンプルアーキテクチャ。
* OpenShift クラスター外のデータセンターサービス（ストレージやデータベースなど）に OpenShift 上の VM を接続する戦略。
* Migration Toolkit for Virtualization オペレーターを使用して、互換性のあるハイパーバイザーから OpenShift Virtualization へ VM を移行する戦略。

=== Virtualization Migration Assessment

* 2 週間のオンサイト対話型ワークショップとフォローアップレポート。
* 経験豊富な Red Hat アーキテクトが、移行の旅路を策定するための短い一連のオンサイトワークショップを実施します。
* ネットワーキング、ストレージ、セキュリティ、バックアップ、災害復旧を含む、仮想化環境とその現在の統合の包括的なレビューを提供します。
* 高レベルの推奨事項と設計上の考慮事項を含む、完全な移行のためのカスタマイズされた提案を記載した VMA レポートを受け取ります。
* 目指す方向、到達方法、所要時間、コストの理解に役立ちます。
